# xai/

Seg-Eigen-CAM explainability. Runs *after* training, because its input is a
trained checkpoint rather than the dataset — that is why it is a separate
folder from `notebooks/`.

```
xai/
├── seg_eigen_cam.py    # shared implementation, used by every notebook here
├── <run_id>/v1.ipynb   # one notebook per trained model
└── out/<run_id>/       # generated heatmaps, not tracked by git
```

`<run_id>` mirrors `notebooks/` and `results/` exactly.

`out/` is gitignored: the heatmaps are regenerated by rerunning the notebook,
so they do not belong in the repository.
